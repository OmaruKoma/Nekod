# Nekod V1.1 Feature Plan — Open-Source WeMod Alternative Roadmap

> **Positioning:** Nekod is an open-source, transparent, player-first alternative to proprietary trainer clients such as WeMod — combining zero-AI, zero-account desktop simplicity for players with open JSON standards, reproducible SHA-256 verification, and optional developer tooling for contributors.

All foundational architecture milestones (**P0–P5**) are complete. V1.1 focuses on closing the day-one **player experience gap** and scaling the **community trainer & plugin ecosystem** without compromising Nekod's security boundaries.

---

## 1. Official & Reference Trainer Examples (`examples/` & `Nekod-Official-Trainers`)

While `examples/sample-singleplayer-rpg/` validates the `declarative_patch_v1` schema and rollback pipeline end-to-end, V1.1 expands working reference trainers across real open-source and indie game targets:

| Priority | Track | Concrete Deliverables |
| :--- | :--- | :--- |
| **P1** | Open-Source / Public Domain Test Games | Ship verified trainers for 2–3 lightweight open-source singleplayer PC games (e.g. Godot/SDL/native C++ binaries) with pinned build IDs and automated smoke fixtures. |
| **P1** | Declarative Pattern Cookbook | Provide worked examples for all four core patterns: AOB signature + offset (`byte_patch`), bounded multi-level pointer chains (`pointer_chain`), periodic scalar locks (`freeze_scalar`), and one-shot triggers (`action`). |
| **P2** | Multi-Build Signature Resilience | Document wildcard AOB best practices and add multi-version regression harnesses in `nekod-validator` + `nekod-trainer-sdk`. |
| **P2** | `.CT` (Cheat Engine Table) Importer Helper | Optional developer-only conversion CLI (`nekod-validator import-ct` or MCP tool) translating safe declarative AOB/pointer entries into draft `trainer.json` + `trainer-manifest.json` packages for human review. |

## 2. Plugin & Community Ecosystem (`L3` / `L4` / `L5`)

To match WeMod's breadth while staying open, auditable, and federated:

1. **WASM Sandbox Host Expansion (`wasm_sandbox_v1`):**
   - Extend `crates/trainer-runtime/src/sandbox.rs` host imports (read-only struct queries, bounded conditional triggers, safe timer hooks) gated strictly behind declared `PermissionScope` entries.
   - Zero raw native `.dll` / `.so` loading for third-party community trainers unless signed & explicitly opted in by the user.
2. **Cryptographic Provenance & `CommunityVerified` Automation:**
   - Support Sigstore / Minisign detached signature verification in `registry-client` alongside SHA-256 manifest digests.
   - Turnkey GitHub Actions template for `Nekod-Community` PR validation (automatic U11 canonical slug check, HTTPS-only artifact reachability, semantic security lint, and automated provenance metadata).
3. **Engine & Runtime Adapter Plugins:**
   - Modular runtime provider specs for Unity (Mono/IL2CPP symbol resolution helper) and Unreal Engine offline metadata lookup while keeping `sdk/runtime-api` OS-neutral.
4. **Contributor CLI Ergonomics (`nekod-validator`):**
   - Add `nekod-validator init` package scaffolding and `nekod-validator verify-live` dry-run attach checks against local test targets.

## 3. WeMod-Grade Desktop UI / UX Optimization (`L1` Desktop)

Making Nekod feel effortless for ordinary players compared to WeMod:

| Area | V1.0 Baseline | V1.1 Enhancement |
| :--- | :--- | :--- |
| **Visual Library & Discovery** | Text list / grid with store badges (`STEAM`, `GOG`, `EPIC`, `CUSTOM`) | Rich game cover art cache (from local store caches / Steam `librarycache`), recently played pinning, one-click **"Play & Attach"** launcher trigger, and instant trainer count/compatibility pills. |
| **Hotkeys & In-Game UX** | Window-focused React `keydown` binding per trainer feature | System-wide OS global hotkeys (works while game is fullscreen/focused), key conflict detection, optional non-intrusive status toast/audio chime on toggle, and Steam Deck / controller chord mapping. |
| **Trainer Presets & Profiles** | Single per-trainer hotkey + toggle map in SQLite | Named presets (*"Story Mode"*, *"No Grind"*, *"Sandbox"*), one-click restore defaults, and JSON profile export/import for community sharing. |
| **First-Run Onboarding** | Empty library until Steam/custom path + manifest added | Guided onboarding checklist, bundled official community feed opt-in sync wizard, and plain-language permission cards highlighting risk levels cleanly. |
| **Localization & Window Polish** | English UI | Community i18n framework (English, Simplified Chinese, Traditional Chinese, Japanese, etc.), system tray minimize ("keep hotkeys active"), and one-click diagnostic bundle export for bug reports. |

## 4. Non-Negotiable Guardrails for V1.1

All V1.1 features remain bound by Nekod's core architectural and security invariants:
- **Zero AI / MCP Requirement for Players:** Every V1.1 UI improvement and plugin workflow functions completely offline without AI keys, subscriptions, or MCP servers.
- **Singleplayer-Only & Anti-Cheat Respect:** Never weaken `ProhibitedOnlineCompetitive` blocks, anti-cheat abort checks, or `PatchLedger` conflict-detection rollback semantics.
- **Strict Layer Isolation:** L1 (`apps/desktop`) remains strictly presentation-only; all OS/memory/registry operations pass through L2 (`nekod-core`) and L3 (`trainer-runtime`).
